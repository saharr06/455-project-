Understanding LSB

Example of hiding a secret bit equal to 1 inside a pixel value of 150.

Original value — 150
10010110
Encoded value — 151
10010111

Absolute error = |151 - 150| = 1

Only the least significant bit changes, minimizing the impact on media quality.
